# Evaluation contract

- Exact rational checks must agree with independent cross-products on generated held-out fraction inputs.
- Algebra solutions must satisfy the original equation by substitution.
- Coding predictions must match independent bounded loops in tests, never eval user text.
- Every posterior sums to 1 and retains nonzero residual mass.
- One ambiguous response must retain multiple explanations.
- Expected information gain is nonnegative within floating-point tolerance; question IDs do not repeat within an unexhausted pool.
- Session import replays bounded validated events rather than trusting supplied posterior values.
- Knowledge search returns the matching teaching passage and preserves provenance; imported content stays inert.
- Browser tests exercise every subject, original fraction scenario, inspector, session round-trip and knowledge import.
- Native smoke tests check main learning workflow and JSON export on Windows, Linux, Intel Mac and Apple Silicon.
- Optional local model integration tests validate the boundary and unavailable-server state. A runtime/model quality benchmark must be reported as unrun unless actually executed. No hardware throughput or calibrated learner-diagnosis claim may be inferred from unit tests.
